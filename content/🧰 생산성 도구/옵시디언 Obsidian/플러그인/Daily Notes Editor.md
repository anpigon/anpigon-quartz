**Daily Notes Editor**은 Roam Research의 기본 일일 노트 뷰와 유사한 방식으로, 여러 일일 노트를 한 페이지에서 인라인으로 편집할 수 있는 Obsidian 플러그인입니다.

[![Daily-Note-View](https://raw.githubusercontent.com/Quorafind/Obsidian-Daily-Notes-Editor/master/image/Daily-Note-View.gif)](https://raw.githubusercontent.com/Quorafind/Obsidian-Daily-Notes-Editor/master/image/Daily-Note-View.gif)

## 주요 기능

- **일일 노트 편집 페이지 열기**:
  - 명령어를 통해 열 수 있습니다.
  - 왼쪽 리본에서 직접 열 수 있습니다.
- **시간 범위별 노트 보기 및 필터링**:
  - 주, 월, 분기, 연도
  - 지난 주, 지난 월, 지난 분기, 지난 연도
  - 전체 노트
  - 사용자 지정 날짜 범위
- **다양한 보기 모드**:
  - **일일 노트 모드**: 일일 노트만 보기
  - **폴더 모드**: 특정 폴더의 모든 노트 보기
  - **태그 모드**: 특정 태그가 있는 노트 보기
- **정렬 옵션**:
  - 생성 시간 기준 (최신/오래된 순)
  - 수정 시간 기준 (최신/오래된 순)
- **커스터마이징 옵션**:
  - 일일 노트의 프론트머터 숨기기
  - 일일 노트의 백링크 숨기기
  - Obsidian 시작 시 일일 노트 편집기 자동 생성 및 열기
- **사용자 정의 프리셋 저장**: 특정 폴더/태그에 빠르게 접근할 수 있도록 프리셋 저장
- **키보드 단축키로 노트 이동**: 위/아래 화살표로 이동
- **폴더 오른쪽 클릭**: 해당 폴더의 모든 노트를 일일 노트 편집기에서 열기

## 설정

- **프론트머터 숨기기**: 일일 노트의 프론트머터 표시 여부 토글
- **백링크 숨기기**: 일일 노트의 백링크 표시 여부 토글
- **시작 시 자동 생성 및 열기**: Obsidian 시작 시 오늘의 일일 노트 생성 및 편집기 열기
- **프리셋 관리**: 특정 폴더/태그에 빠르게 접근할 수 있도록 프리셋 저장 및 관리

## 사용 방법

1. **왼쪽 리본의 달력 아이콘 클릭** 또는 **"Open Daily Notes Editor" 명령어 실행**
2. **뷰 내 액션 버튼 사용**:
   - 시간 범위 선택 (주, 월, 분기, 전체 등)
   - 보기 모드 변경 (일일, 폴더, 태그)
   - 정렬 순서 변경
3. **현재 선택을 프리셋으로 저장**하여 빠르게 접근
4. **파일 탐색기의 폴더 오른쪽 클릭**: 해당 폴더의 모든 노트를 일일 노트 편집기에서 열기
