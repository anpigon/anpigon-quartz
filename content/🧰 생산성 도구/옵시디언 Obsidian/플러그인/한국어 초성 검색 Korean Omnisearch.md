Obsidian용 고급 한국어 검색 엔진으로, 초성(초성 자음), 중성(중성 모음), 종성(종성 자음) 검색 기능을 갖추고 있으며, 강력한 콘텐츠 인덱싱 및 퍼지 매칭 기능을 제공합니다.

## 📦 설치 방법

1. [BRAT 플러그인](https://github.com/TfTHacker/obsidian42-brat)을 설치하고 활성화합니다.
2. BRAT 설정에서 **"베타 플러그인 추가"**를 클릭합니다.
3. 다음 GitHub URL을 입력합니다: `https://github.com/BrianJChoi/obsidian-korean-omnisearch`
4. **"플러그인 추가"**를 클릭하여 설치합니다
5. 설정 → 커뮤니티 플러그인으로 이동하여 **"Korean Omnisearch"**를 활성화합니다
