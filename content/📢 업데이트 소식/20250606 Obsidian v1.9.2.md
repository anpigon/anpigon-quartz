## v1.9의 새로운 기능
[Bases](https://help.obsidian.md/bases)를 소개합니다. Bases는 모든 노트 집합을 강력한 데이터베이스로 변환할 수 있는 새로운 핵심 플러그인입니다. Bases를 사용하여 프로젝트부터 여행 계획, 독서 목록 등 모든 것을 정리할 수 있습니다.

![bases-view](https://obsidian.md/images/changelog/2025-05-21-bases.png)

Bases를 통해 볼트 내 데이터를 시각화하고 상호 작용할 수 있는 사용자 지정 테이블 뷰를 생성할 수 있습니다. 속성별로 노트를 필터링하고 공식을 생성하여 동적인 속성을 도출할 수 있습니다.

모든 베이스 데이터는 로컬 마크다운 파일과 YAML에 저장된 속성으로 백업됩니다. Bases를 지원하기 위해 `.base` 파일 형식과 [구문](https://help.obsidian.md/bases/syntax)을 도입했습니다.
**중요:** 이것은 초기 베타 버전입니다. 앞으로 몇 달 동안 Bases에 많은 변경 사항과 개선 사항이 있을 것으로 예상되며, 평소보다 긴 얼리 액세스 기간이 될 것입니다. 계획된 기능 중 일부는 더 많은 뷰 유형, 플러그인 API 및 Publish 지원을 포함합니다. [Bases 로드맵](https://help.obsidian.md/bases/roadmap)을 참조하십시오.

## 새로운 기능
- 새로운 **각주 뷰** 핵심 플러그인은 현재 파일의 각주를 노트에서 위치를 잃지 않고 관리하는 데 도움이 되는 새로운 사이드바 탭을 추가했습니다.

## 변경 사항
- `tag`, `alias`, `cssclass` 속성에 대한 지원을 공식적으로 제거하고 `tags`, `aliases`, `cssclasses`를 사용하도록 변경했습니다. 또한, 이 속성들의 값은 반드시 목록이어야 합니다. 현재 값이 텍스트 속성인 경우 Obsidian에서 더 이상 인식되지 않습니다.

## 개선 사항
- 접기 아이콘을 클릭해도 호버 미리보기가 더 이상 숨겨지거나 편집 모드로 전환되지 않습니다.
- "PDF 내보내기" 흐름에서 내보내기 버튼이 이제 초기 키보드 포커스를 받습니다.
- 파일 또는 폴더 제안을 표시하는 설정에서 더 나은 일치를 위해 이제 퍼지 검색을 사용합니다.
- 공백이 이제 동기화 기록 및 파일 복구 차이에서 올바르게 표시됩니다.
- 다크 모드에서 텍스트 선택 대비가 증가했습니다.
- 동기화 기록 뷰에 이제 파일 복구에서 영향을 받은 파일을 열 수 있는 버튼이 포함됩니다.
- 동기화 기록 뷰에 이제 파일 이름이 변경되기 전과 후가 표시됩니다.
- 파일 복구가 이제 비마크다운 파일의 제목과 제안에 파일 확장자를 표시합니다.
- 현재 탭이 고정된 경우, "현재 탭 닫기" 명령은 탭을 닫는 대신 고정을 해제합니다. 명령을 반복하면 탭이 닫힙니다.
- "파일 이동" 옵션은 파일 플러그인이 비활성화된 경우에도 계속 사용할 수 있습니다.
- "파일 저장" 명령은 파일이 활성화되었을 때만 명령 팔레트에 나타납니다.
- 고유 노트 접두사 플러그인에 이제 선택한 텍스트를 연결하기 위한 "고유 내부 링크 추가" 명령이 포함됩니다.

## 수정된 사항
- 명령 팔레트 결과 정렬 방식이 개선되었습니다. 기본적으로 결과는 이제 알파벳순으로 정렬됩니다. 그리고 최근에 사용된 명령이 검색 결과에서 더 높은 순위를 차지합니다.
- 파일을 편집해도 아웃라인 뷰에서 접힌 섹션이 더 이상 초기화되지 않습니다.
- 캔버스 카드가 이제 내부 오류를 생성하지 않고 콜아웃을 지원합니다.
- 텍스트 속성 내에서 `Shift-Enter`를 눌러도 더 이상 빈 입력이 생성되지 않습니다.
- 검색 후 테이블 셀을 탐색할 때 커서 위치가 이제 정확합니다.
- "Obsidian 프레임" 창 프레임 스타일을 사용할 때, 팝아웃 창에서 현재 열려 있는 파일을 표시하도록 창 제목이 이제 올바르게 업데이트됩니다.
- 콜아웃 내에서 편집할 때 목록 번호 매기기가 일관되게 유지됩니다.
- PDF 뷰가 백그라운드에서 열렸을 때 더 이상 포커스를 빼앗지 않습니다.
- 엄격한 줄 바꿈이 이제 콜아웃의 첫 번째 단락에서 제대로 렌더링됩니다.
- 노트에 각주가 포함된 경우 아웃라인 뷰가 이제 올바른 줄을 강조 표시합니다.
- 부분적으로 완성된 HTML을 포함하는 마크다운 테이블이 이제 올바르게 렌더링됩니다.
- 탭 기록 버튼, 웹 뷰어 기록 항목, 북마크된 URL, 노트를 여는 리본 항목이 이제 보조키를 존중하고 "새 탭에 포커스" 환경설정을 따릅니다.
- 캔버스가 `Ctrl-C`를 눌렀을 때 선택된 노트를 일관되게 복사합니다.
- 태그 뷰가 검색 필터를 지울 때 올바르게 업데이트됩니다.
- 코드블록 자동 완성 시 들여쓰기와 커서가 목록 항목 내에 있는지 여부를 이제 올바르게 고려합니다.

## 개발자
- `document.body`에 추가된 CSS 속성이 이제 모든 팝아웃 창에 미러링됩니다.
- `ButtonComponent`는 `onClick` 이벤트가 비동기인 경우 자동으로 로딩 스피너를 표시합니다.
- 이제 웹 뷰어를 우회하고 `window.open(url, 'external')`을 사용하여 URL을 사용자 기본 브라우저에서 열도록 지정할 수 있습니다.
- `idb`가 버전 8.0.2로 업데이트되었습니다.
- `yaml`이 버전 2.7.0으로 업데이트되었습니다.
- 동일한 객체를 여러 키에 할당할 때 의도치 않은 참조를 방지하기 위해 YAML 별칭이 비활성화되었습니다.
- `processFrontmatter`를 통해 동일한 객체를 여러 키에 할당해도 더 이상 YAML 별칭이 생성되지 않습니다.
