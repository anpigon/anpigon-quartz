## Ollama 0.9.1

## 도구 호출 개선

### 새로운 도구 호출 지원

다음 모델들은 이제 도구 호출을 지원합니다:
- [DeepSeek-R1-2508](https://ollama.com/library/deepseek-r1:671b) (671B 모델)
- [Magistral](https://ollama.com/library/magistral)

다음 모델들의 도구 호출 신뢰성도 개선되었습니다:
- [Llama 4](https://ollama.com/library/llama4)
- [Mistral](https://ollama.com/library/mistral)

모델을 재다운로드하려면 `ollama pull` 명령을 사용하십시오.

## 새롭게 선보이는 macOS 및 Windows 미리보기

![](https://i.imgur.com/XR9OVvp.png)

macOS와 Windows용 Ollama 애플리케이션의 새로운 버전을 테스트하여 초기 피드백을 수렴할 수 있습니다.

향후 출시 버전에서 다음과 같은 개선사항이 도입될 예정입니다:

- [macOS용 다운로드](https://github.com/ollama/ollama/releases/download/v0.9.1/Ollama-Preview.dmg)
- [Windows용 다운로드](https://github.com/ollama/ollama/releases/download/v0.9.1/OllamaSetup-Preview.exe)

피드백을 제출하려면 GitHub에 `app` 라벨이 붙은 이슈를 등록하십시오. 이 앱들은 Ollama의 향후 버전으로 자동 업데이트되므로, 새로운 미리보기 버전을 다시 다운로드해야 할 수 있습니다.

### 새로운 기능

- **네트워크 상에서 Ollama 노출**: Ollama를 이제 네트워크에 노출시킬 수 있어 다른 디바이스나 인터넷을 통해 접근이 가능합니다. 이는 성능이 낮은 디바이스에서 강력한 Mac, PC 또는 Linux 컴퓨터에서 실행 중인 Ollama를 사용하려는 경우에 유용합니다.
- **로컬 브라우저 접근 허용**: 로컬 Ollama 설치본을 웹사이트에서 접근할 수 있도록 합니다. Ollama의 [JavaScript 라이브러리](https://github.com/ollama/ollama-js)를 사용하는 브라우저 기반 애플리케이션 개발에 유용합니다.
- **모델 저장경로**: 모델을 외장 하드디스크나 기본 디렉토리의 대안 위치에 저장할 수 있도록 모델 저장 경로를 수정할 수 있습니다.
- **적은 용량 및 macOS에서 빠른 시작**: macOS 앱은 이제 네이티브 애플리케이션으로 훨씬 빠르게 시작되며 훨씬 적은 설치 공간을 요구합니다.

## 변경사항

- [Magistral](https://ollama.com/library/magistral) 모델은 이제 '주절설명 모드'를 비활성화할 수 있게 되었습니다. 참고: 이 경우 시스템 프롬프트를 변경하는 것이 권장됩니다.
- 이전에 `POST predict` 라고 표시된 오류 메시지가 이제 더 많은 정보를 표시합니다.
- 일부 모델의 도구 호출 신뢰성 개선
- Windows에서 `ollama run` 명령으로 Ollama가 자동으로 시작되지 않던 문제 수정
