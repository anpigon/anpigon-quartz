# Ollama 0.9.3

## Gemma 3n
Ollama에서 이제 [Gemma 3n](https://ollama.com/library/gemma3n)을 지원합니다.

Gemma 3n 모델은 노트북, 태블릿, 휴대폰 등 일상적인 기기에서 효율적으로 실행되도록 설계되었습니다. 이 모델들은 140개 이상의 구어(口語) 데이터로 훈련되었습니다.

### Effective 2B
```
ollama run gemma3n:e2b
```

### Effective 4B
```
ollama run gemma3n:e4b
```

## 주요 변경 사항
* Apple Silicon Mac에서 오류가 제대로 보고되지 않던 문제를 수정했습니다.
* Ollama는 이제 모델이 훈련된 컨텍스트 길이로 제한하여, 이상한 오버플로우 동작을 방지합니다.

**전체 변경 내역**: https://github.com/ollama/ollama/releases/tag/v0.9.3

---

**번역 해설:**

* **문장의 핵(Head) 중심 번역:** 각 문장에서 가장 중요한 의미를 전달하는 동사나 명사를 중심으로 번역을 구성했습니다. 예를 들어, "Ollama now supports Gemma 3n"에서는 'supports'가 핵심이므로 "Ollama에서 ~을 지원합니다"로 번역했습니다.
* **자연스러운 한국어 표현:** 원문의 의미를 정확히 전달하면서도 한국어 사용자가 읽었을 때 어색함이 없도록 자연스러운 표현을 사용했습니다. 예를 들어 "designed for efficient execution"은 "효율적으로 실행되도록 설계되었습니다"로, "What's Changed"는 "주요 변경 사항"으로 번역했습니다.
* **전문 용어 유지:** 'Gemma 3n', 'Ollama', 'Apple Silicon Mac', 'context length', 'overflow behavior' 등은 기술 문서에서 통용되는 전문 용어이므로 그대로 유지하거나 가장 적절한 번역어를 사용했습니다.
* **구어(口語) 추가:** 'spoken languages'의 경우, 단순히 '말하는 언어'보다는 '구어(口語)'라는 전문 용어를 괄호와 함께 표기하여 정확성을 높였습니다.
