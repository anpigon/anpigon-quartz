## Gemma 3n
Ollama에서 이제 [Gemma 3n](https://ollama.com/library/gemma3n)을 지원합니다.

Gemma 3n 모델은 노트북, 태블릿, 휴대폰 등 일상적인 기기에서 효율적으로 실행되도록 설계되었습니다. 이 모델들은 140개 이상의 구어(口語) 데이터로 훈련되었습니다.

### Effective 2B
```
ollama run gemma3n:e2b
```

### Effective 4B
```
ollama run gemma3n:e4b
```

## 주요 변경 사항
* Apple Silicon Mac에서 오류가 제대로 보고되지 않던 문제를 수정했습니다.
* Ollama는 이제 모델이 훈련된 컨텍스트 길이로 제한하여, 이상한 오버플로우 동작을 방지합니다.

**전체 변경 내역**: https://github.com/ollama/ollama/releases/tag/v0.9.3
