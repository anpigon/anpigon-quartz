## 개요

이 **디렉터리**는 R2R 도커 **컨테이너** 내부에 **마운트**되며, 사용자 지정 구성 **파일**을 위한 **것**입니다. 여기에 **배치된** 모든 **파일**은 **컨테이너**에서 **실행되는** **애플리케이션**에 **접근 가능**합니다.

## 사용법

1. 사용자 지정 구성 **파일**을 이 **디렉터리**에 **배치**하십시오.
2. `r2r.env` 또는 `r2r-full.env` **파일**에서 `R2R_CONFIG_PATH`를 **설정**하십시오.

## 구성

**애플리케이션**은 사용자가 **설정한** 환경 **변수**를 **사용**하여 구성 **파일**을 **찾습니다**:

```
R2R_CONFIG_PATH=/app/user_configs/<config>.toml
```

다른 **파일 이름**을 **사용**하려면, 환경 **파일**의 `R2R_CONFIG_PATH` **변수**를 **업데이트**하여 사용자 지정 **파일**을 **가리키도록** 하십시오. 예를 들어:

```
R2R_CONFIG_PATH=/app/user_configs/my_custom_config.toml
```

## 문제 해결

구성 **오류**가 **발생**하면 다음을 **확인**하십시오:

1. 구성 **파일**이 이 **디렉터리**에 **존재하는지**
2. **파일 이름**이 `R2R_CONFIG_PATH`에 **지정된** **것**과 **일치하는지**
3. **파일**이 적절한 **권한**(읽기 가능)을 **가지고 있는지**
4. **파일**이 유효한 TOML **구문**을 **포함하는지**

더 자세한 구성 **정보**는 주요 **문서**를 **참조**하십시오.
