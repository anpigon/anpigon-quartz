> [!summary]
> Google I/O를 앞두고 Gemini 2.5 Pro가 업데이트되었습니다. 주요 개선 사항으로는 프론트엔드/UI 개발 능력 향상, 코딩 작업 및 에이전트 워크플로우 생성 능력 개선, 비디오 이해 능력과 코딩 결합, 신규 기능 개발 용이성 증대 등이 있습니다. aistudio.google.com에서 무료로 사용해볼 수 있습니다.



![[Pasted image 20250509232235.png]]

Google은 I/O 2025 개발자 컨퍼런스를 앞두고 Gemini 2.5 Pro의 업데이트된 버전인 Gemini 2.5 Pro Preview (I/O 에디션)을 2025년 5월 6일에 출시했습니다. 이 모델은 코딩 능력, 특히 매력적인 인터랙티브 웹 앱 구축에 크게 향상되었습니다.

## 주요 특징 및 개선 사항

- **향상된 코딩 기능**: 코드 변환, 코드 편집, 복잡한 에이전트 워크플로우 개발 기능이 개선됨.
- **WebDev Arena 리더보드 1위**: 시각적으로 매력적이고 기능적인 웹 앱 구축 능력을 측정하는 벤치마크에서 1위 (1499.95점, 이전 버전 1278.96점 대비 147 Elo 포인트 상승).
- **비디오 이해 능력**: VideoMME 벤치마크에서 84.8% 점수로 최첨단 성능.
- **코드 생성 성능**: LiveCodeBench v5 벤치마크에서 70.4%에서 75.6%로 성능 향상.
- **함수 호출 개선**: 함수 호출 오류 감소 및 트리거율 개선.
- **긴 컨텍스트 처리**: 현재 100만 토큰 컨텍스트 창 제공, 곧 200만 토큰으로 확장 예정.
- **다양한 활용**: 텍스트, 코드, 오디오, 이미지, 비디오 등 다양한 형식 처리 가능.

## 접근 방법

- Gemini 2.5 Pro Preview (I/O 에디션)은 Gemini API를 통해 Google AI Studio 및 Vertex AI에서 사용 가능.
- Gemini 앱 사용자도 Canvas와 같은 기능을 통해 업데이트된 모델 이용 가능.
- 기존 Gemini 2.5 Pro 사용자는 별도 조치 없이 동일한 가격으로 개선된 모델 사용 가능.

## 개발자 및 업계 반응

- **Cognition**: 백엔드 라우팅 시스템의 복잡한 리팩토링을 성공적으로 완료한 최초의 모델로 평가.
- **Cursor**: 도구 호출 실패가 현저히 감소했다고 보고, 코드 에이전트에 통합.
- **Replit**: 기능과 지연 시간 간의 균형이 뛰어난 모델로 평가.

## 활용 사례

- YouTube 비디오 기반 인터랙티브 학습 앱 제작.
- 단일 프롬프트로 기능적이고 아름다운 UI 웹 앱 제작.
- 음성 받아쓰기 앱 개발 및 마이크 UI 애니메이션 코딩.
- 코드 리팩토링, 최적화, 다국어 번역 작업 수행.

## 성능 비교 (이전 모델 대비)

- **코딩 능력**: WebDev Arena Leaderboard에서 147 Elo 포인트 차이로 이전 버전 압도.
- **응답 속도 및 지침 처리**: 일부 사용자 피드백에 따르면 응답 속도가 느려지고 지침 처리 능력이 약화되었다는 의견 있음.
- **암시적 캐싱**: 반복적인 컨텍스트 비용 절감을 위해 암시적 캐싱 지원.

## 향후 전망

- Google은 Gemini 2.5 Pro의 API 개선, 자율 코딩 에이전트 개발, 투명성 향상을 계획 중.
